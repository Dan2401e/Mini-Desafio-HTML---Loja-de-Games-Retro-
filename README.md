# 🎮 GameZone Retro — Mini Desafio HTML

Este projeto foi desenvolvido como parte de uma atividade prática de **HTML**, com o objetivo de criar uma página promocional simples para uma loja fictícia de jogos clássicos chamada **GameZone Retro**.

A proposta do desafio é trabalhar os principais elementos da estrutura HTML utilizando **HTML puro**, sem a necessidade de CSS ou JavaScript.

## 📋 Sobre o Projeto

A página representa uma loja especializada em **games e consoles retrô**, apresentando informações de forma simples, organizada e funcional.

O desafio possui como principal regra a criação de uma página com **no máximo 50 linhas de código HTML**, incentivando a utilização de uma estrutura objetiva e bem organizada.

## 🎯 Objetivos da Atividade

Durante o desenvolvimento foram praticados conceitos fundamentais de HTML, incluindo:

* Estrutura básica de uma página HTML;
* Títulos e parágrafos;
* Textos em **negrito** e *itálico*;
* Criação de listas;
* Links internos e externos;
* Inserção de imagens;
* Criação de tabelas;
* Organização e indentação do código;
* Desenvolvimento dentro de uma quantidade limitada de linhas.

## 🕹️ Elementos Implementados

A página conta com os principais requisitos propostos no desafio:

| Elemento          | Implementação                                     |
| ----------------- | ------------------------------------------------- |
| 📄 Estrutura HTML | Estrutura básica com `html`, `head` e `body`      |
| 📝 Texto          | Títulos e parágrafos informativos                 |
| ✨ Formatação     | Uso de `strong` e `em`                            |
| 📋 Lista          | Lista de consoles/jogos retrô                     |
| 🔗 Link interno   | Navegação utilizando âncora                       |
| 🌐 Link externo   | Acesso a uma página externa                       |
| 🖼️ Imagem         | Imagem relacionada ao universo retrô              |
| 💰 Tabela         | Produtos e respectivos preços                     |
| 📏 Limite         | Código desenvolvido dentro do limite de 50 linhas |


## 🧰 Tecnologias Utilizadas

* **HTML5**
* Editor de código — Visual Studio Code
* Navegador Web para testes

> O projeto foi desenvolvido utilizando somente **HTML**, conforme solicitado na atividade.

## 🎮 Tema

O tema escolhido foi uma **loja de games retrô**, utilizando elementos relacionados aos consoles e jogos clássicos.

A ideia é transmitir uma identidade simples de uma loja especializada em produtos nostálgicos do mundo dos videogames.

## 📚 O que foi aprendido

Com esta atividade foi possível praticar conceitos básicos e importantes de HTML, principalmente a utilização correta de elementos para estruturar uma página.

Também foi possível entender como **listas, tabelas, imagens e links** podem ser combinados para criar uma página funcional sem depender de outras tecnologias.

## 🚀 Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em qualquer navegador.
4. Navegue pela página e teste os links disponíveis.

## 🏆 Desafio

O principal desafio do projeto foi conseguir incluir todos os elementos solicitados mantendo o código **simples, organizado e com menos de 50 linhas**.

A atividade demonstra que é possível criar uma página funcional utilizando apenas os fundamentos do HTML.
